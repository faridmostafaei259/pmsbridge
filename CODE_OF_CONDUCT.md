# Code of Conduct

We want pmsbridge to be a welcoming project for everyone.

- Be respectful and constructive. Critique ideas, not people.
- No harassment, discrimination, personal attacks, or sharing of others' private information.
- Assume good intent and help newcomers.

Maintainers may remove comments, commits, or contributions that violate this code, and may block repeat
offenders. Report problems privately to the repository owner, [@faridmostafaei259](https://github.com/faridmostafaei259),
through the contact options on their GitHub profile.
