  1. In your assistant's settings, find where you add a connector, custom connector or remote MCP server, and add a new one.
  2. Name it, for example "pmsbridge", and paste the address above. Leave any client ID or secret fields empty.
  3. Choose Add, then Connect. A pmsbridge page opens in your browser.
  4. Sign in with your pmsbridge e-mail and password (and two-factor code if you use one).
  5. Check which assistant is asking, tick the connections it may use, and choose Allow access.

Each person connects with their own pmsbridge account, and the assistant acts only for that person. The assistant then appears on this page.
