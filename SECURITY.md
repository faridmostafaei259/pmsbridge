# Security policy

## Reporting a vulnerability

Please report vulnerabilities privately using GitHub's "Report a vulnerability" feature on this repository
(Security tab). Do not open a public issue. We aim to acknowledge reports within 3 business days.

Include the affected version, steps to reproduce, and the impact you observed. Never include real PMS
credentials or guest data in a report.

## Supported versions

Security fixes are released for the latest minor version. Installations with automatic patch updates
enabled (the default) receive them automatically.
