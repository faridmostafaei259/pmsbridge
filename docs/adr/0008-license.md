# 0008. License: Elastic License 2.0

- Status: accepted
- Date: 2026-11-22

## Context
The project should be free for any property management company to run, modify and self-host for its own
business. The maintainers do not want third parties to sell it as a hosted or managed service. Permissive
licenses (MIT, Apache-2.0) and the AGPL all allow paid hosting.

## Decision
License the project under the Elastic License 2.0 (ELv2). It allows use, modification and self-hosting,
including commercial use for one's own business, and prohibits providing the software to others as a hosted
or managed service.

## Consequences
- The project is source-available, not open source in the OSI sense. Public documentation says
  "source-available".
- Contributors license their contributions under the same terms.
- Some organizations only accept OSI-approved licenses; they may not be able to adopt the project.
